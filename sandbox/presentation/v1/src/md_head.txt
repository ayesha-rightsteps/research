# Deck v1 — slide-by-slide text and speaker notes

This file is generated by `src/build_deck.py` from the same calls that build `deck_v1.pptx`, so the two cannot drift
apart. **Do not edit it by hand**: change `src/build_deck.py` and rebuild (see `README.md`).

- **On slide** = the text, tables and boxes on the slide. **Image** = the picture file in `images/`.
- **Say** = the speaker notes (also stored in the notes pane of the .pptx), in plain English for the presenter.
- Method names are always the full names. "MAPPO + PAH (no assignment)" is the ablation that some figures call
  "Hungarian off".
- Numbers come from the result tables of the repository (`v4/03-base-paper-baselines/output/eval_summary.md`,
  `v4/04-base-paper-experiments/output/phase3_summary.md`, `docs/research/11_thesis_reporting_notes.md`); the build
  stops if a number is not found there.

**Length:** 29 main slides (about 28 to 30 minutes) + 14 appendix slides for questions.
**Short path for 15 minutes (17 slides):** 1, 2, 3, 5, 6, 7, 9, 11, 12, 14, 15, 18, 24, 25, 26, 27, 28; keep 29 for the
questions.
**Likely questions and answers:** `qa_prep.md`.
